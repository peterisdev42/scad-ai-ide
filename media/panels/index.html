GitHub API access

SCAD AI IDE uses the GitHub API to load releases and other project data. Requests are anonymous by default and subject to GitHub's anonymous API rate limit.

If a section reports a rate-limit error, you can authorize SCAD AI IDE to use the access token for your GitHub account in VS Code. Requests will then use your account's higher API limit.
