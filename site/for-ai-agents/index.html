FOR AI-ASSISTED CAD

AI that can inspect the workspace, not just write code.

SCAD AI IDE registers native VS Code Language Model Tools that can call the same domain services as the GUI. A supported Agent can request bounded actions and inspect structured evidence, while the editor and user retain control.

Current availability: Source-first development preview; there is no official Marketplace installer or GitHub Release yet. Features described here are implemented in source, with real-host Agent and cross-platform acceptance still ongoing.

Real service-backed Agent capabilities

The current source registers 53 native Language Model Tools, 12 Skills and 2 Instructions. Registration and deterministic tests establish interfaces—not end-to-end autonomous success for every model or platform. Read the generated capability catalog for tool-level evidence.

Runtime

Inspect available OpenSCAD builds, select a runtime or request installation/management operations using the Runtime service.

Libraries

Discover audited library versions, inspect project/global state, install or restore exact pinned dependencies subject to trust and permissions.

Customizer

Read parameters and presets, set bounded values, analyze source authoring changes, and reject stale edits using revision/hash checks.

CAD evidence

Request CSG diagnostics, raw mesh measurement, frozen views, static assembly checks and comparisons of snapshot-bound reports.

An example of a bounded CAD workflow

  1. Inspect: Agent checks which runtime and project dependencies are available.
  2. Act with scope: when authorized, it adjusts a Customizer parameter or requests an exact-version library operation.
  3. Analyze: it requests CLI/mesh checks and reads actual issue details or frozen evidence, instead of treating a screenshot as a pass.
  4. Report: the Agent distinguishes PASS, FAIL and UNRESOLVED results, and asks for human input if evidence is incomplete.

This is a supported workflow model, not a promise that every model/host combination completes it autonomously. The verification guide and acceptance progress document outstanding cases.

Permissions, human authority and snapshot boundaries

  • Workspace Trust: operations that require trusted code or workspace file access are gated.
  • Independent approval: destructive deletion and privileged writes require service-side authorization; a model-supplied boolean cannot grant it.
  • Stale-state protection: revisions, content hashes and snapshot identities guard against edits or results applied to old models.
  • Unresolved means unresolved: absence of a diagnosed issue is not proof of watertightness, mechanical safety or successful 3D printing.
  • Live availability: registration may exist while a tool is unavailable under the current host, provider, policy or environment.

See the GUI/Agent service and permissions matrix.

What this integration does not promise

SCAD AI IDE does not currently bundle its own language model or ship a standalone MCP server. It contributes native VS Code Language Model Tools that compatible Agent hosts may discover and invoke. Tool registration is not a guarantee that all providers support the calls or that arbitrary autonomous CAD tasks will succeed.

CAD analysis is designed around bounded evidence, not a “guaranteed printable” certification. The separate experimental Fast CSG mode currently has specific macOS ARM64 and Preview Exporter requirements. Windows native CLI paths with some Unicode characters have a known failure case in the tested build.
