SOURCE-FIRST SETUP

Run the SCAD AI IDE development version.

SCAD AI IDE is currently a source-first development preview, not a published VS Code Marketplace extension. Follow this guide to explore the real installed extension rather than treating the website's precompiled Three.js STL demo as a working CAD compiler.

Current availability: Source-first development preview; there is no official Marketplace installer or GitHub Release yet. Features described here are implemented in source, with real-host Agent and cross-platform acceptance still ongoing.

Prerequisites and honest release status

Before you begin, install a compatible Visual Studio Code 1.140.0+, Node.js 24, npm and Git. Building the OpenSCAD language server from source may additionally require Rust/Cargo and platform build tools. Ensure the project and its submodules are cloned completely.

There is no official Marketplace package or GitHub Release installer yet. The source instructions in the README Quick Start are the authoritative reference if the build process changes.

Clone, build and launch

git clone --recurse-submodules https://github.com/peterisdev42/scad-ai-ide.git
cd scad-ai-ide
npm ci
npm run prepare:lsp
npm run compile

Open the repository in VS Code and press F5 to launch the Extension Development Host. If a prebuilt LSP cannot be prepared, consult CONTRIBUTING.md for platform-specific Rust and build prerequisites.

First model checklist

  1. In the Extension Development Host, open a trusted workspace containing a saved .scad file.
  2. Open Quick Access → Runtime and select an available OpenSCAD CLI.
  3. Run SCAD AI IDE: Open as Preview and inspect the mesh with camera controls.
  4. Use Customizer to adjust supported parameters or presets; export from a runtime-supported mode.
  5. Optionally run Analyze Model Diagnostics or Verify Raw CAD Mesh. Read UNRESOLVED as incomplete evidence, never as a pass.

Use Cmd + Shift + V on macOS or Ctrl + Shift + V on Windows/Linux to switch source/preview.

Want to try the demo first?

The homepage's interactive cheese preview loads a precompiled STL mesh and a visible OpenSCAD source file. Three.js powers the camera interaction; the web page does not run the OpenSCAD compiler and is not embedded VS Code. It demonstrates 3D navigation without replacing the native extension's full workflow.

Compatibility and limitations

Agent tool availability depends on the running VS Code host and model provider. Cross-platform host/model acceptance is ongoing; the tested Windows native CLI has failures for some Unicode source/output/library paths. Experimental Fast CSG preview currently needs an additional exporter on supported macOS ARM64 configurations.

See the README's current limitations before treating the project as production-ready. Bugs and contributions are welcome at GitHub Issues.
