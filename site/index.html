TRANSPARENT PROJECT STATUS

Built and testable.
Still being validated.

SCAD AI IDE is an active, source-first project—not a general-availability release. Core IDE and native Agent interfaces exist, but final host, model and platform acceptance is not complete.

Read CAD acceptance progress ↗

Available from source

Runtime, Libraries, Preview, Customizer, language support, diagnostics and native Agent Tools can be exercised in the Extension Development Host.

Validation in progress

Complete model-driven CAD workflows, real interaction and default Agent host compatibility still have open acceptance cases.

Cross-platform limitation

The tested Windows native OpenSCAD CLI has reproducible failures with some Unicode source, output and library paths. A full cross-platform release is not signed off.

See investigation ↗

No official installer yet

There is currently no published GitHub Release installer or Marketplace listing. Start from source and follow the setup guide.
