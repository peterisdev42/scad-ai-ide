Library and dependency management

Dependencies you can restore.

Discover OpenSCAD libraries through SCAD Registry, select an exact version, and restore a project on another machine using its declaration and lockfile. A shared global store supports multiple versions and project-local mounts; OpenSCAD processes receive a project-scoped OPENSCADPATH.

  • Registry / Global / Project views
  • Exact Tag or Snapshot Commit selection
  • Commit-pinned dependency restoration
  • Shared versioned cache and local links
  • Verify, repair and clean up cached libraries

Exact versions only; no automatic recursive dependency solver. Copy fallback requires confirmation; some Windows non-ASCII paths remain a known CLI limitation.

CAD verification and design review

Go beyond a successful render.

Inspect CLI-backed CSG diagnostics and raw meshes, measure frozen geometry, check declared static assembly constraints and compare reports. Preserve evidence and request surface-specific human feedback.

  • CSG diagnostics and issue details
  • Raw STL/3MF topology and mesh checks
  • Frozen geometry measurements and PNG views
  • Declared-part static assembly checks
  • Report comparison, baselines and spatial feedback
  • Explicit-profile build-envelope and overhang screening

PASS, FAIL and UNRESOLVED describe tested evidence only. Printability remains NOT_CHECKED; no manufacturing guarantee, motion-path or general mechanical proof.

Native AI Agent integration

Give agents CAD-aware tools.

Supported VS Code Agent hosts can access the same bounded domain services as GUI actions. Native tools, skills and instructions connect environment setup, parameter editing, diagnostics, geometry evidence and design review.

  • Inspect runtimes and libraries; request authorized changes
  • Read and adjust Customizer parameters and presets
  • Analyze model diagnostics and raw mesh evidence
  • Check declared assembly constraints and compare reports
  • Request human spatial feedback and return interactive preview links
  • Control integration, groups and individual tools in the AI panel

No bundled LLM or MCP server. Host/provider support, Workspace Trust, permissions and stale-state checks apply. Registered tools do not establish reliable autonomous-model acceptance.

GET STARTED

Start in the editor you already know.

Currently run from source. Requirements: VS Code 1.140.0+, Node.js 24, npm and Git; Rust/Cargo and platform build tools may be required for the LSP.

git clone --recurse-submodules https://github.com/peterisdev42/scad-ai-ide.git
cd scad-ai-ide
npm ci
npm run prepare:lsp
npm run compile

Launch the development host

Open the repository in VS Code and press F5. Open a trusted workspace with a saved .scad file, select a runtime, then open Preview and adjust parameters with Customizer.

COMMON QUESTIONS

Frequently asked questions.

What is SCAD AI IDE?

An independent, GPL-3.0 open-source OpenSCAD development environment inside Visual Studio Code, designed for humans and AI agents.

Is it a standalone CAD application?

No. It is a VS Code extension that integrates the OpenSCAD engine, editor and project tooling.

How is it different from a preview extension?

Its differentiator is the combination of managed runtimes, exact project dependencies, language support, visual customization, CAD evidence and bounded native Agent Tools.

Is it suitable for beginners?

Once running, the GUI reduces environment and library setup friction, and Preview and Customizer make parameterized geometry approachable. The current source build still requires developer tooling.

Can I use multiple OpenSCAD versions?

Yes. Runtime Manager discovers, installs and selects available CLI builds or custom executables.

Can I install BOSL2?

Yes, where the registry version and layout are supported. Install an exact version in Libraries and include BOSL2/std.scad.

Does it support dependency lockfiles?

Yes. .scad/dependencies.json declares exact versions and .scad/dependencies.lock.json pins the repository, commit and mount layout.

Can projects use different library versions?

Yes. The global store supports multiple versions, while each project has its own mounts and OPENSCADPATH.

Does it resolve transitive dependencies?

No automatic recursive dependency resolution or arbitrary version ranges are provided.

Can I preview OpenSCAD inside VS Code?

Yes. The extension offers an interactive 3D Preview editor, with navigation, measurement and supported exports.

Does the website run OpenSCAD in the browser?

No. It uses the actual Preview WebView inside Code-OSS Workbench, with geometry compiled from the actual cheese.scad source at build time.

Can I change model parameters without rewriting source?

Yes. Customizer applies parameter overrides and supports OpenSCAD-compatible presets.

What can AI agents do?

Supported hosts can use native tools to inspect the environment, request authorized runtime and library changes, adjust parameters and obtain CAD evidence and review results.

Does it provide an MCP server or bundled AI model?

No. Its current integration uses native VS Code Language Model Tools, Skills and Instructions; availability depends on the host and provider.

Does it guarantee a printable model?

No. CAD checks are evidence-scoped and printability remains NOT_CHECKED; limited explicit-profile screening is not manufacturing certification.

Can it verify mesh geometry and assemblies?

Yes, within the supported raw mesh checks and explicitly declared static assembly constraints. Insufficient evidence can produce UNRESOLVED.

Can I install it from the Marketplace today?

No. It is a source-first development preview, with no official Marketplace entry or GitHub Release installer at this audited revision.

What are the requirements?

VS Code 1.140.0 or newer, Node.js 24, npm and Git; source LSP builds may additionally require Rust/Cargo and platform tools.

Which features are experimental?

Fast CSG on supported macOS ARM64 setups and visual-only per-part coloring. Cross-platform and real-agent acceptance are still ongoing.

Is SCAD AI IDE affiliated with OpenSCAD or Microsoft?

No. It is an independent community project.
