What is SCAD AI IDE?

An independent, open-source Visual Studio Code extension for OpenSCAD. It connects language support, interactive 3D preview, runtimes, libraries, Customizer and CAD verification in one workspace.

How is it different from the OpenSCAD desktop IDE?

OpenSCAD is the language and engine. SCAD AI IDE integrates OpenSCAD work into VS Code, adding managed toolchains, dependency locks and Agent operations. It is not affiliated with OpenSCAD. Compare workflows.

Why use it rather than a preview-only extension?

Several extensions already provide Three.js or WASM previews. SCAD AI IDE adds project-aware runtimes, pinned libraries, Customizer and CAD evidence integrated with native Agent services. This combination is distinctive, not exclusive.

Is it beginner-friendly?

Once running, it can reduce library/runtime setup friction and connect code to 3D geometry through preview and Customizer. The source-first development preview itself still requires Node.js, Git and VS Code. Read the beginner guide.

Does it require AI?

No. Editing, preview and runtime/library operations can be used manually. Native VS Code Agent Tools are optional and their availability depends on the host and model provider.

What can native Agents do?

Supported Agents can inspect runtime/library state, adjust parameters and request bounded CAD diagnostics, mesh checks or review, subject to permissions and state checks. Registration does not prove autonomous success, and no MCP server is currently shipped. Read the safety boundaries.

Can I get it from the Marketplace today?

Not yet. SCAD AI IDE is a source-first development preview without an official Marketplace listing or GitHub Release installer. Build it from source.

How does project library management work?

The library manager pins exact versions in project declarations and locks, shares a versioned global store, and injects project-scoped OPENSCADPATH. Arbitrary version ranges and recursive transitive dependency resolution are not supported. Read the design.
