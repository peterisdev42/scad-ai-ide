DIFFERENTIATED BY INTEGRATION

Why another OpenSCAD extension?

An interactive Three.js preview or AI-assisted source generation alone is not unique. SCAD AI IDE is designed around the combination: one VS Code project, managed native OpenSCAD toolchains, reproducible libraries, parameter controls and evidence-aware Agent actions.

Current availability: Source-first development preview; there is no official Marketplace installer or GitHub Release yet. Features described here are implemented in source, with real-host Agent and cross-platform acceptance still ongoing.

The distinctive combination, with evidence

One project workspace

Language tooling, native CLI preview/export, Customizer, library and runtime management stay beside your source, Git and terminal.

Exact-version libraries

Project dependency declarations and lock files, a versioned global store, restore operations and project-scoped OPENSCADPATH keep dependencies explicit.

CAD evidence beyond visual plausibility

CSG diagnostics, raw mesh inspection, measurements, static declared assembly checks and comparisons expose what has actually been tested.

Native Agent actions

VS Code Language Model Tools call bounded domain services also used by the GUI, with explicit permissions and snapshot-aware results.

Choose what works for you

Choose the official desktop IDE when…

You want the official OpenSCAD standalone workflow and do not need VS Code-specific tooling.

Choose a lightweight WebAssembly preview when…

Low-friction, no-native-install preview is more important than managed native CLI versions and project evidence workflows.

Choose SCAD AI IDE when…

You value its integrated, source-controlled workflow and want to experiment with native, bounded VS Code Agent operations. Current source-first setup and open acceptance cases are real costs. Review the setup guide before deciding.

Be specific about what is still unfinished

SCAD AI IDE is a source-first development preview without an official Marketplace listing or GitHub Release installer. Several Agent host/model scenarios remain under acceptance; certain Windows Unicode paths fail using the tested native CLI; Fast CSG uses an experimental macOS ARM64-specific path. CAD verification does not certify printability.

These are not hidden footnotes: the current state is documented in the README and the product claim ledger.
