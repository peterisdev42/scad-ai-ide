FOR OPENSCAD BEGINNERS

Learn OpenSCAD by seeing your code become geometry.

OpenSCAD is a programmable 3D modeling tool. SCAD AI IDE helps you make sense of the source, preview, parameters and libraries in one familiar VS Code workspace—not by hiding how OpenSCAD works.

Current availability: Source-first development preview; there is no official Marketplace installer or GitHub Release yet. Features described here are implemented in source, with real-host Agent and cross-platform acceptance still ongoing.

Why a visual, integrated workflow helps

Understand code through a 3D view

Open a saved .scad file, inspect the rendered mesh, orbit and zoom it, and learn how edits change shapes. Preview and export depend on the selected runtime.

Change parameters without hunting through code

Customizer exposes supported variables as controls and presets; source code stays central to the modeling workflow.

Manage OpenSCAD runtimes

Runtime Manager can discover and select compatible CLI versions rather than requiring you to manage every runtime path yourself.

Bring libraries into your project

Libraries Manager supports audited library versions, project declarations, exact pins and restore from a lock file.

A first model, step by step

The current extension is not a public one-click installer. Start by following the source setup guide. Once the Extension Development Host is running:

  1. Open a trusted VS Code workspace and save a .scad file.
  2. Select an available OpenSCAD runtime in Quick Access → Runtime.
  3. Use SCAD AI IDE: Open as Preview to inspect the result.
  4. Adjust supported dimensions with Customizer, or edit the OpenSCAD source directly.
  5. Optionally inspect diagnostics and export supported mesh formats.

Want something concrete right now? Download the website's cheese.scad source or precompiled STL. The online demo renders that static STL with Three.js; it does not compile OpenSCAD in your browser.

What does “less setup” really mean?

After the extension is running, it can inject a project-scoped OPENSCADPATH, manage versions of the OpenSCAD CLI and restore declared external libraries. That is different from installing SCAD AI IDE itself.

Current installation prerequisites: VS Code 1.140.0 or later, Node.js 24, npm and Git. If the bundled/prebuilt language server cannot be prepared, Rust/Cargo and platform build tools may also be needed. See the exact build commands.

Library dependencies are pinned to exact versions, not solved from arbitrary ranges. Cross-platform acceptance remains in progress; some non-ASCII Windows CLI paths are known to fail in tested builds.

Can beginners use it without an AI model?

Yes. The core workflow works through regular editor commands, preview, Customizer and management UI. A supported VS Code Agent can optionally operate the same bounded services, but it is not required for learning OpenSCAD.

An Agent may help inspect runtime state, adjust parameters or request CAD checks. It cannot be assumed to reliably solve every design problem or certify a mesh as printable. Learn how Agent tools are gated.

What it is—and what it isn't

  • Not a drag-and-drop replacement for OpenSCAD syntax: learning code remains useful.
  • Not the official OpenSCAD desktop IDE: the extension integrates into VS Code and launches OpenSCAD processes.
  • Not generally available yet: the first public workflow is source-first development.
  • Not a live web compiler: the home demo uses an offline-generated STL mesh.

For technical limitations consult the README validation notes.
