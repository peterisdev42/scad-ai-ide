# SCAD AI IDE brand assets

The primary icon is a yellow wedge of cheese with translucent green cavities, representing parametric Solid CAD / Boolean subtraction.

- `../icon.png`: optimized transparent 256 × 256 PNG used by VS Code Marketplace and Open VSX.
- `../scad.svg`: simplified monochrome 24 × 24 Activity Bar icon.
- `cheese.svg`: editable *approximate vector interpretation* of the full-color render (also used as the website favicon).
- `../../site/assets/cheese.png`: website copy of the store icon, so Pages remains standalone.

The 3D raster render and its simplified SVG are intentionally not pixel-identical. The site deploys automatically on changes under `site/**`.
