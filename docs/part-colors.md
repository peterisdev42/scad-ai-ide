# 实验性按零件着色

Preview 左侧颜色按钮下方的 **Color parts separately** 开关用于辅助观察装配关系。关闭后恢复原有颜色；手动选择统一颜色会退出按零件着色模式。它只修改预览外观，不改写 SCAD、预设或导出的模型。

## 按需 CSG 辅助

默认预览不导出 CSG。打开该开关后，SCAD Preview 在模型显示后按需请求一次辅助导出，使用当前选中的 OpenSCAD CLI、当前参数和未保存的源码。`$preview` 与当前预览模式保持一致。

从 CSG 中提取颜色作用域、树路径及世界坐标包围盒，优先使用源码显式颜色；没有颜色时使用树路径产生的固定配色。网格按三角形重心匹配空间范围，优先匹配较小的包含范围。没有可用辅助数据时继续使用原有的网格连通体配色。直接打开的 STL / 3MF 文件没有源码，因此不运行 CSG 导出。

该功能只读取元数据，不在 TypeScript 中重建 Boolean 几何，也不重新导出每个零件。CSG 变化不会替换模型网格或重置相机。

## 性能与生命周期

- 请求等待 150 ms，吸收快速参数变化；不阻塞模型显示。
- 同一模型版本复用辅助数据，重复切换、相机移动和主题变化不再次导出 CSG。
- 新模型版本使旧缓存失效；关闭开关、开始下一轮渲染或关闭面板会取消尚未完成的辅助导出，迟到结果不覆盖新模型。
- 导出进程设置 2.5 s 超时，输出最多 2 MiB；解析限制 300,000 个 token、20,000 个节点、128 层节点嵌套和 256 个分组。
- 网格辅助匹配设置每次外观更新约 80 ms 的预算；单网格超过 1,000,000 个顶点或预算用尽时保留连通体配色。匹配结果缓存，不在每帧重新计算。
- 失败、超时和不支持的结构只回退到原有着色，诊断记入 Preview 输出通道。

## 已知边界

这是空间范围辅助，不是精确的零件身份识别。重叠、嵌套、相同包围盒、共享索引顶点和改变树结构的条件分支仍可能出现误判。导入几何、复杂拉伸等尚不支持的结构可能没有辅助范围。CSG 中的普通 group 也不一定代表实际零件。

目前处理 cube、sphere、cylinder、polyhedron 及常见分组、变换和 Boolean 容器的保守范围；difference 使用正操作数范围，intersection 使用保守合并范围，不进行实体求值。优先保留外层 color 作用域；没有可用显式颜色作用域时尝试顶层分组。

## 本机样本

2026-11-03，macOS ARM64、Node.js 24.16.0，使用已有本机 OpenSCAD Runtime 对 `scalable_field_camera/SCAD/assembly.scad` 验证：

- `explode=0/1` 分别得到 27 个作用域；标识与源颜色保持一致。
- CSG 约 188 KiB；两次独立导出约 76 / 45 ms。
- CSG 解析短程采样约 3–6 ms。
- 两份最终 STL 约 82,048 / 83,532 个三角形；辅助匹配短程样本约 9–18 ms，缓存后的外观更新约 0.02 ms。

这些是单机短程样本，不是跨平台性能保证。包围盒命中也不等于视觉归属完全正确。

自动化覆盖按需请求、缓存、取消、旧版本丢弃、失败回退，以及接触几何在装配/展开后使用相同源颜色。
