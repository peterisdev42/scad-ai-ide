# Phase 3: declared static assembly

Baseline: `2385de712f4ea97ee0463b9316a097315b281512`; branch `codex/cad-parts-assembly`. Depends on unmerged Phase 2 PR #3 and Phase 1 PR #2. Implementation does not merge or publish either dependency.

The optional `.scad/verification.json` schema is packaged locally. `PartRegistry` validates strict JSON, references and obvious conjunctive conflicts; it does not judge geometry. Relative entry/file paths resolve from the project root containing `.scad`, including `./model.scad` and `./lid.stl`. Stable identity is `(canonical Manifest URI, author part ID)`, independent of geometry, display name and declaration order. Sources remain workspace guarded and trusted. Tools never create or edit this file or fetch a `$schema` URL.

`AssemblyVerificationService` freezes every entry before any export, acquires leases for frozen evidence, reuses selector-specific P2 exports, verifies original non-empty solid prerequisites, invokes the assembly Worker, evaluates rules separately and rechecks every input before storing an immutable v3 report. V1 diagnostics and V2 mesh reports retain their existing meanings. Historical reads never execute the source. A Manifest digest is an explicit repair precondition; changed thresholds cannot silently replace the original repair goal.

`AssemblyKernel` consumes raw decoded Float64 meshes, applies column-vector `T Rz Ry Rx` once after intrinsic 3MF transforms and preserves triangle indices/instance provenance. Display Float32 STL is a separate derived artifact. A versioned `ASW1` artifact retains little-endian Float64 positions, Uint32 indices and part/instance provenance.

Distances use triangle point/edge candidates and segment/face intersection behind a conservative BVH branch bound. Coordinates are interpreted as exact dyadic Float64 values. BigInt rational squared distances and witness coordinates are converted to outward-rounded intervals whose endpoints are verified by exact comparisons. P2 error estimates are never treated as certified bounds. These results describe frozen exported meshes, not exact analytic CAD surfaces or certified transcendental rotation values.

Material classification uses deterministic exact winding rays for every surface component, retaining cavities; a 3MF document uses the union of instance material. Positive boundary distance alone does not rule out containment. Surface intersection does not by itself prove material overlap. Verified interior samples establish overlap for coincident/crossing solids; contact requires a separating support plane plus exact zero surface distance. Cases without a certificate remain UNRESOLVED. Rigid geometry retains P2 validity requirements; volume constraints use a separate exact enclosure rather than absolute signed volume. Complex 3MF union volumes remain unavailable when not proven.

Facts are independent of constraints. Required checks form a conjunction and use `FAIL > UNRESOLVED > SKIPPED > PASS`. Every part's non-empty raw validity is required. No user-declared required constraints means no overall PASS. Additional pair queries cannot skip required checks. Total assembly volume, overlap volume, motion, thickness and printability are not checked.

The host shares the existing Problems collection, Dispatcher, OperationTracker, artifact store, PNG renderer and native image adapter. Source problems remain independent of Preview owners. Manifest issues use JSON positions; geometry failures refer to rule positions and bounded spatial evidence without inventing SCAD parameter lines. Runtime invalidation is scoped to assemblies using SCAD; pure mesh facts remain usable without OpenSCAD.

Normative references checked during implementation: [3MF Core](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md), [OpenSCAD CLI](https://files.openscad.org/documentation/manual/Using_OpenSCAD_in_a_command_line_environment.html), [VS Code tools](https://code.visualstudio.com/api/extension-guides/ai/tools). Acceptance results and remaining limits are recorded separately in `phase3-acceptance.md`; this architecture document is not a PASS certificate.
