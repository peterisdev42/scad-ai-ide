# SCAD AI IDE — approved product positioning
Reviewed: 2026-11-23. Canonical site: https://peterisdev42.github.io/scad-ai-ide/

## One-sentence definition
SCAD AI IDE is an open-source, agent-ready OpenSCAD development environment inside Visual Studio Code. It brings language tooling, interactive 3D preview, runtime and library management, parametric customization and evidence-aware CAD verification into one workflow.

## What is distinctive
The **combination**, not an exclusive individual feature: managed CLI runtimes + project-aware exact-version libraries + Customizer + CAD evidence + native VS Code Language Model Tools that share bounded services with the GUI.

## Why beginners benefit, after installation
The running extension presents runtime/library setup in a UI, connects source with interactive preview, and makes parameter editing approachable. **Current installation is from source**, requiring developer tooling; never promise a one-click Marketplace installation.

## Why AI users benefit
Supported VS Code Agent hosts can call bounded tools to inspect environment state, adjust parameters or request diagnostic/mesh/review operations, under permission, trust and stale-state checks. **A tool's registration is not proof of autonomous success**; this is not an MCP server or bundled LLM. CAD results are evidence-scoped rather than printability certification.

## Editorial rules
- Never claim "world's only", "best", "guaranteed printable" or universal agent/OS support.
- Do not call the website an in-browser OpenSCAD compiler: it displays geometry compiled from cheese.scad during the website build using the real Preview in Code-OSS Workbench.
- Keep implementation, acceptance-in-progress, experimental and unsupported states distinct.
- Evidence sources and review dates are tracked in product-claims.json; reflect any change in README, site, JSON-LD and tests.
- Do not imply availability of a Marketplace listing, release installer or a paid AI subscription that is not live.

## Audited differentiators
See [the comparison notes](competitor-audit.md). Competing extensions already provide Three.js previews, WebAssembly-based preview and AI-assisted modeling. Describe the **integrated project-aware workflow**, not unsupported exclusivity.
