# Website design system

The website uses a native HTML/CSS implementation of the public [Geist Design System](https://vercel.com/geist/introduction), including neutral color scales, Geist Sans/Mono, heading/copy hierarchy, 12-column guide layout, thin borders, accessible buttons and focus states. It is not Vercel's private component implementation. Brand yellow is reserved for technical accents and the existing logo. The initial visit is light regardless of OS preference; the theme toggle persists an explicit selection and synchronizes the actual Code-OSS Workbench and Preview. No external font requests in the deployed site; fonts are copied from pinned geist npm package with its OFL license. The embedded workbench remains native VS Code UI rather than being restyled as a marketing component.

The only canonical product page is the root. Eight capability anchors are grouped into infrastructure, design experience and CAD intelligence. Old public routes remain compatibility redirects. Diagrams are explicitly illustrative, not actual screenshots or claimed test output. The existing interactive Preview remains real. Product screenshots and recorded agent sessions are still follow-up work requiring an actual running extension; do not invent them. The static product manifest and HTML are checked against package and claim ledger in CI; update them together when facts change. Independent live GEO evaluation, browser screenshots and full CI are required before acceptance. Umami remains out of scope.
